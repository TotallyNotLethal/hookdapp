# Required Binary Assets

The Android shell expects the following binary files to be present when building locally:

- `gradle/wrapper/gradle-wrapper.jar` – Gradle wrapper runtime copied from a matching Capacitor/Gradle installation (e.g., generated by `npx cap add android`).
- Launcher icons placed under `app/src/main/res/mipmap-*/`:
  - `ic_launcher.png`
  - `ic_launcher_foreground.png`
  - `ic_launcher_round.png`
- Splash screens placed under `app/src/main/res/drawable*/`:
  - `splash.png` for each density bucket (both `drawable` and density-specific folders such as `drawable-land-xxxhdpi`, `drawable-port-mdpi`, etc.).

These assets are generated by Capacitor when scaffolding the Android project. If they are missing, regenerate them by running `npx cap add android` (or `npx cap sync android`) in an environment where the Capacitor CLI can create the platform assets, then copy the resulting binaries into this repository before building the Android app.
